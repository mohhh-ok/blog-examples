# 生成音声のライセンス

このディレクトリの wav ファイルは ElevenLabs の API (`eleven_v4`) で生成した音声です。
再利用する場合は ElevenLabs の利用規約に従ってください。

## 参照音声について

クローン元の参照音声 (`../08-26-fish-voice-clone-consistency/reference/ref.wav`) はリポジトリ所有者本人の声で、
クローン生成物の公開を所有者が許諾しています。参照音声そのものは非公開 (git 管理外) です。

`baseline/` の 1 本はクローンではなく、ElevenLabs のライブラリ音声 (Shohei) で生成した音声です。
