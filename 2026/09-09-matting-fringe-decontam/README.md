# 透過動画の輪郭に残る生成背景色を測る／消す

対応記事: 2026-09-09 「透過動画の輪郭に生成背景色が残る」

単色背景で動画を生成し、AI マッティングで抜いて alpha 付きで配信する経路で、半透明の縁と
不透明の最外周に生成背景色が残る症状を扱います。記事で使った 2 つのスクリプトを、
プロジェクト固有の部分を外して置いています。

- `fringe_metrics.py` — 縁に背景色が残っているかを測る
- `bg_alpha_cut.py` — 背景色とほぼ同色の縁の画素を透明にする（後処理）

## 必要なもの

- Python 3.11+
- numpy, Pillow
- ffmpeg / ffprobe（PATH に通っていること）

```bash
uv venv --python 3.11 .venv
source .venv/bin/activate
uv pip install numpy Pillow
```

## fringe_metrics.py

```bash
# 彩度の高い背景（マゼンタ・緑）
python fringe_metrics.py --cutout cutout.mov --bg FF00FF

# 無彩色グレー背景 + 取りこぼしも測る
python fringe_metrics.py --cutout cutout.mov --raw source.mp4 --bg 808080
```

3 つの指標を出します。

| 指標 | 何を見るか | 向いている背景 |
|---|---|---|
| `semi_bias` | 半透明画素が背景色の色相方向へどれだけ寄っているか。マゼンタなら `(R+B)/2 - G`、緑なら `G - (R+B)/2` | 彩度の高い背景 |
| `fringe_near_bg_pct` | 輪郭帯のうち、背景色とのユークリッド距離が 30 未満の画素の割合 | 無彩色背景（`semi_bias` が使えない） |
| `dropped_pct` | 元動画で前景だった画素のうち、抜いたあと透明になった割合 | 全部（湯気・毛先の消失検出） |

深さ帯は alpha==255 を 3x3 の最小値フィルタで 1 回ずつ収縮した差分で定義します。外側から
ring1 / ring2、深さ 3px 以上を inner と呼びます。inner はキャラ本来の色なので、後処理の
前後で inner が変わっていたら意匠を壊しています。

平均だけを見ると打ち消し合って消えるので、`over20_pct`（偏りが +20 を超える画素の割合）も
一緒に出します。

`dropped_pct` は面積の変動係数やループ継ぎ目の差では代替できません。湯気のように全体面積の
数 % しかない構造は、まるごと消えても面積の統計にほとんど出ません。

## bg_alpha_cut.py

```bash
python bg_alpha_cut.py --in frame.png --out fixed.png --bg 808080 --threshold 90
```

輪郭帯（半透明画素と、不透明の深さ 1〜2px）のうち、色が背景色とほぼ区別できない画素の
alpha を 0 にします。安全弁が 2 つ入っています。

1. 深さ 3px 以上の不透明画素は絶対に触らない
2. 参照色 `F_ref`（inner の色を外側へ伝播させたもの）が背景色に近い画素は処理対象から外す。
   被写体が背景と同系色の布を着ている場合に、その布ごと消すのを防ぐ

透明にした画素の RGB は最近傍の前景色で埋めます。4:2:0 で書き出すと、透明画素の RGB が
クロマサブサンプリングで隣の不透明画素へにじむためです。

`--threshold` は素材ごとに実測して決めます。欠陥画素と意匠色の「背景色からの距離」を
ヒストグラムで見て、そのあいだに置きます。既定値は仕様ではなく、ある 1 本の現在値です。

## 動画へ適用する

どちらのスクリプトもフレーム単位の処理なので、動画へ流すときは ffmpeg の rawvideo で
つなぎます。

```bash
ffmpeg -i cutout.mov -pix_fmt rgba -f rawvideo - \
  | python your_pipe.py --bg 808080 \
  | ffmpeg -f rawvideo -pix_fmt rgba -s 768x768 -r 24 -i - \
      -c:v prores_ks -profile:v 4444 -pix_fmt yuva444p10le out.mov
```

中間は ProRes 4444 のようなロスレス寄りの形式にします。lossy に落としたあとで縁を触ると、
圧縮で崩れた色を材料にすることになります。

## 記事に書いた結論

後処理は効きますが、上限があります。抜いたあとのフレームには「元の前景色 F」と
「背景色 B」を分離するための情報がもう残っていません。背景色を素材の色と紛れない
低彩度の無彩色にして生成し直すほうが、後処理より確実でした。AI マッティングは色で
キーを抜いていないので、クロマキーのような派手な色を付ける理由がありません。
